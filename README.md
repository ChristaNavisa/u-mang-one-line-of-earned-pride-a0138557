A program that writes one line — a quiet, earned moment of pride — to `/output/entry.txt`.

## The line

> He practised the knot a hundred times on the dock, and today the rope held, the boat stayed, and his father nodded once.

120 characters. A boy who has practised a knot a hundred times finally ties it right, and his father's single nod is the whole reward: concrete scene, effort you can feel, pride that lands on the last word.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (deterministic; the same line on every run).
